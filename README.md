# Siyaj Confidential Reporting

أنشئ مشروع منصة ويب عربية باسم سِياج (Siyaj)، وهو نموذج أولي لمنصة تساعد ضحايا الابتزاز الإلكتروني على تقديم البلاغات بسرية وأمان، وتساعد الموظفين المختصين على مراجعتها.

في هذه المرحلة أريد إنشاء أساس المشروع فقط، دون بناء الصفحات أو ربط قاعدة البيانات أو خدمات الذكاء الاصطناعي.

اجعل المشروع يدعم اللغة العربية واتجاه RTL، ويكون متجاوبًا مع الكمبيوتر والجوال، مع تنظيم الكود بطريقة Feature-Based Modular Architecture قابلة للتطوير والصيانة والاختبار.
